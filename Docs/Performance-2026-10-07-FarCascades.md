# Stock old-pipeline far-cascade actor policy

Installed MyGeometryRendererOld.TrimCullProxies requires CastShadows, not IsCulled,
and for cascade index>=4 requires DrawOutsideViewDistance. MyProxiesFactory maps
that proxy flag from the entity RenderFlags directly. The captured scene uses the
old renderer. New-pipeline FirstFullyContainingCascadeIndex trimming must not be
applied to these old actors.

Vulkan previously replayed ordinary actors into all six fitted cascades. The
experimental SE_VULKAN_STOCK_FAR_CASCADES=1 policy retains fitted near bits0–3,
preserves all fitted bits for flagged actors, and leaves voxel submission alone.
It changes no resolution, LOD distance, light-frustum fit or quality threshold.
It is off by default until broader scene/source selection and pixel checks.

Scene suite65 checks passes with zero core/synchronization validation errors.
Tests cover unflagged/flagged masks, near rejection, actual prepared packet masks,
and policy disable revalidating batch hints without pose changes. Earlier fitted
caster, camera/freeze/disable, size, highlight and mutation checks remain enabled.
