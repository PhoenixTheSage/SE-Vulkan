# Anomaly early product contract

Anomaly remains the pack host. SE-Vulkan records copied commands and owns native
resources, barriers and retirement. Guest feature bit21 adds flag4096 to existing
ABI-1 fullscreen packets; packet size/version and public marks are unchanged.

The flag accepts isolated (compose=5) mark1 raster programs writing an existing
owned 2D color image. It rejects renderer-owned targets, volumes, arrays, buffers,
depth images, compute/geometry/extended contracts and other flags. Pinned catalog
IDs remain valid owned image IDs. Anomaly uses it only for CameraVelocity,
LinearDepth, HiZ and ReactiveClear. HistoryCopy stays at its public slot.

These products execute after GBuffer, object motion and opaque decals, before
AO/lighting. Internal replay mark7 maps to mark1 graphics/layout semantics and
skips these packets at normal mark1 replay. Public callback ordering stays
BeforeFullscreen, ordinary passes, AfterFullscreen. Public replay still admits
only marks1–6. No early replay/frame refresh occurs without an early product.
Frame end/reset clears selection state.

The optional legacy 2D fallback now transitions Undefined -> TransferDst, clears
RGBA zero, then transitions to shader-read visibility for fragment and compute.
Required extended inputs still fail admission when absent. This establishes
zero texels; it does not claim DX11 null GetDimensions or full typed/array/volume/
buffer null-resource parity.

StageBindingFacadeContracts loads actual Anomaly core and DX11 assemblies to
check pending/active routing and reflection compatibility. EarlyOwnedRegression
uses actual shaders/native readback for current-frame early products, exact
execution count, callback order, negative alpha, zero fallback, invalid packets
and 50/75/100% DRS in synchronous and pipelined recording. Both fixtures belong
to focused native-stage and full recreation gates.

Shared registration facades are available; native reserved descriptors remain
unimplemented and unadvertised. Aggregate named-stage and same-draw attachment
support remain false. Windows live acceptance is waived for the active goal;
remaining automated contracts and qualification are still required.
