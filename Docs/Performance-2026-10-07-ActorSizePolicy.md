# Experimental stock actor size culling

The installed old DX11 projected-size contract is implemented behind
SE_VULKAN_ACTOR_SIZE_CULLING=1, default off. It uses raw nearest-bounds distance,
maximum authored LOD distance, authoritative local extent when parented and world
extent when unparented. It projects only beyond the final authored distance and
requires absolute pixel-area strictly below20. The FOV/aspect/near projection and
projection offsets follow MyRender11.SetupCameraMatricesInternal. It does not add
a new quality threshold or apply global/cube LOD multipliers to size culling.

Old MyGeometryRendererOld.PrepareFilter skips IsCulled actors in main, depth and
probe paths. This implementation removes their normal packet preparation and
freezes their LOD state. Model/motion/FOV/viewport/mode changes re-evaluate state.
Transitions invalidate legacy occlusion and dirty static/dynamic spot maps; native
cached cascade membership sees packet removal. Stock highlights draw authored
LOD0 separately: culled highlighted actors retain individual8192 highlight-only
packets and remain excluded from normal views. Static/skeletal ownership remains
outside this experimental selector until its own contract is verified.

The production scene suite passes52 checks with zero core/synchronization
validation errors: exact20 and final-distance boundaries, zero-distance guard,
extent/viewport, removal and restore across both slots, parented reentry, scale
replacement and actual highlight rendering with the postprocess lane enabled.
The initial highlight test incorrectly expected draws with its fixture postprocess
lane disabled; the fixture now enables the existing production path.
